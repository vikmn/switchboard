# Logo assets

Flat vector logo + icon suite for switchboard. The mark is a patch-panel /
crossbar switch: a green cable (TL→BR) crossing over an amber cable (BL→TR) on a
4×4 jack field — echoing switchboard's ● active / ○ expired status colours and
its idea of routing identity by context.

| File | Use |
|------|-----|
| `switchboard-logo.svg` / `.png` | full square logo with monospace wordmark (README header) |
| `switchboard-icon.svg` / `.png` | mark only, 1:1 (social preview, app icon) |
| `switchboard-icon-64.png` | 64×64 |
| `switchboard-icon-32.png` | 32×32 favicon |

## Palette
- Background `#1e1e2e` (terminal charcoal)
- Green cable/jacks `#00ff9f` (active)
- Amber cable/jacks `#ffb454` (expired/other)
- Inactive jacks: rim `#363a4f`, socket `#24273a`
- Wordmark `#cdd6f4`, lowercase monospace, letter-spacing 0.22em
